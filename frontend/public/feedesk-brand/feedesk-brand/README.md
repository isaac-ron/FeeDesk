# FeeDesk Brand Assets
Version 1.0

This package contains all official FeeDesk brand assets.

## Quick start

1. Use `logos/svg/feedesk-logo-primary.svg` as your default logo on light backgrounds
2. Use `logos/svg/feedesk-logo-dark.svg` on dark backgrounds or dark mode UIs
3. Use `logos/svg/feedesk-icon-only.svg` for favicons, app icons, and avatars
4. Import `assets/colors.css` for CSS custom properties
5. Copy `assets/tailwind-tokens.js` contents into your `tailwind.config.js`

## Fonts

The logo references Manrope — load it from Google Fonts:
```html
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;600;700;800&display=swap" rel="stylesheet">
```
